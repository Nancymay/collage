# Вырезки

Карманная мастерская коллажей из букв и фактур, найденных на улице. Одна самодостаточная страница `index.html`: без сборки, зависимостей и внешних картинок.

## Что умеет

- **Вырезать.** Сфотографировать или выбрать фото и сохранить из него несколько находок:
  - **буква** — обвести контур точками или рамкой и указать символ (кириллица, латиница, цифры, знаки);
  - **узор** — выделить рамкой кусок ткани, обоев или плитки; он сохраняется цельным фрагментом, без повтора;
  - **картинка** — фигурная вырезка с прозрачным фоном или прямая обрезка.

  Фото увеличивается щипком или кнопками. При перетаскивании точки появляется лупа.
- **Касса.** Наборная касса с ячейкой на каждую букву и стопкой найденных вариантов, образцы узоров и картинки. У каждой вырезки есть кнопка «В коллаж».
- **Стол.** Лист с инструментами «Слово», «Вырезка» и «Бумага».
  - Слово собирается из букв кассы, тап по букве меняет её вариант. Слово можно перемешать или разложить на отдельные буквы. Недостающие буквы видны карандашным контуром.
  - Узор кладётся лоскутом, полоской или на весь лист. Свои узоры растягиваются одним куском, а у демоузоров (клетка, плитка, обои) при растягивании становится больше клеток; масштаб рисунка настраивается отдельно.
  - Элементы двигаются, поворачиваются, меняют размер и порядок слоёв. Есть отмена и экспорт в PNG 1080 px.

При первом открытии в кассе лежит демонабор, а на столе готова открытка «ПРИВЕТ».

## Запуск

Откройте `index.html` в браузере. Для локального сервера подойдёт, например:

```
python3 -m http.server
```

Коллекция и текущий коллаж хранятся в IndexedDB этого браузера.
